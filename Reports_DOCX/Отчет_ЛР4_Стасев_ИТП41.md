## Ход работы
1. Развертывание mock REST API: в корне репозитория подготовлен файл db.json с ресурсом /cards. В качестве сервера использован публичный сервис my-json-server.typicode.com/stasev/RPiPiP-DiscountCards (допустимо по общим требованиям).

2. Сетевой слой на Combine: создан протокол CardsAPIClientProtocol и реализация DiscountCardsAPIClient. Запрос формируется через URLSession.shared.dataTaskPublisher(for: urlRequest).

3. Конвейер обработки Combine: применены операторы: tryMap (проверка HTTP статус-кодов 200..<300), decode(type:decoder:) для DTO в стиле snake_case, mapError для приведения к единому типу APIError, retry(1) для однократного повторения при сбоях сети.

4. Служба синхронизации SyncService: загрузка и слияние данных. Алгоритм слияния (applySnapshot) сопоставляет записи по remoteId: новые карты с сервера вставляются, неизмененные обновляются. Карты, созданные пользователем локально (remoteId == nil) или помеченные locallyModified = true, никогда не перезаписываются. Удаленные пользователем серверные карты фиксируются в модели DeletedRecordEntity, чтобы повторный запуск не вернул их обратно.

5. Индикатор состояния синхронизации SyncStatusRow: отображение статуса синхронизации вверху главного экрана (анимация загрузки, "Данные с сервера загружены: добавлено 6, обновлено 0", кнопка повтора при ошибке сети).

6. Экспорт данных в отчуждаемый файл CardExporter: формирование JSON-файла для импорта между пользователями и CSV-файла для электронных таблиц (с разделителем ";" и кодировкой UTF-8 BOM для корректного открытия в Microsoft Excel).

7. Интеграция системного меню «Поделиться»: вызов стандартного компонента ShareLink(item:preview:) для передачи сгенерированного файла через AirDrop, мессенджеры или сохранение в «Файлы».

8. Поиск на лету DebouncedSearch: класс на базе Combine PassthroughSubject с операторами debounce(for: .milliseconds(250)) и removeDuplicates(), устраняющий лишние перерисовки во время ввода символов пользователем.

9. Тестирование: разработано 24 модульных теста (с имитацией ответов через URLProtocolStub), подтверждающих устойчивость к сетевым ошибкам 503, сохранение локальных карт и корректность генерации CSV/JSON экспорта.

## Контрольные вопросы
### 1. Опишите последовательность шагов для выполнения базового сетевого запроса с использованием URLSession.
1) Создание экземпляра URL с проверкой валидности адреса; 2) Создание объекта URLRequest (установка HTTP-метода, заголовков Content-Type, Accept, таймаута); 3) Выбор конфигурации URLSession (shared, default или ephemeral); 4) Создание задачи dataTask(with:completionHandler:) или dataTaskPublisher(for:); 5) Запуск задачи вызовом task.resume(); 6) Обработка ответа в замыкании (проверка ошибок транспорта, проверка HTTP-статуса ответа, десериализация бинарных данных Data через JSONDecoder) с обязательным переходом на главный поток DispatchQueue.main при обновлении интерфейса.

### 2. Что такое фреймворк Combine? Опишите его фундаментальные компоненты.
Combine — это декларативный реактивный Swift-фреймворк для обработки асинхронных событий во времени. Фундаментальные компоненты: 1) Publisher (издатель) — протокол, объявляющий тип испускаемых значений Output и тип ошибки Failure, генерирующий события во времени; 2) Subscriber (подписчик) — принимает значения и завершение (completion/failure); 3) Operators (операторы) — методы-трансформаторы потока (map, filter, tryMap, debounce, zip, flatMap); 4) Subscription (подписка) — связующее звено, контролирующее обратное давление (backpressure).

### 3. С помощью какого встроенного метода URLSession можно получить издателя (Publisher) для выполнения сетевого запроса? Что он возвращает в качестве данных и ошибок?
Метод URLSession.shared.dataTaskPublisher(for: URLRequest). Он возвращает издателя типа URLSession.DataTaskPublisher. При успешном выполнении издатель передает кортеж (data: Data, response: URLResponse), а в случае ошибки завершается с ошибкой типа URLError.

### 4. Как связать цепочку операторов Combine со слоем данных и трансформировать сырые бинарные данные в готовые объекты?
Цепочка связывается последовательными операторами: dataTaskPublisher(for: request) -> .tryMap { data, response in guard let http = response as? HTTPURLResponse, (200..<300).contains(http.statusCode) else { throw APIError.badStatus } return data } -> .decode(type: [CardDTO].self, decoder: JSONDecoder()) -> .mapError { APIError.from($0) }. Таким образом байты трансформируются в строго типизированные структуры DTO.

### 5. Что такое AnyCancellable? Что произойдет с сетевым запросом, если коллекцию cancellables не сохранить в классе ViewModel?
AnyCancellable — это стирающий тип токен управления подпиской, реализующий протокол Cancellable. При вызове метода cancel() или при деинициализации (deinit) объекта AnyCancellable подписка автоматически аннулируется. Если не сохранить AnyCancellable в наборе Set<AnyCancellable> (или свойстве класса), переменная будет уничтожена сразу после выхода из области видимости метода, и сетевой запрос будет немедленно отменен системой до получения ответа.

### 6. Для чего используются операторы .subscribe(on:) и .receive(on:)?
Оператор .subscribe(on: scheduler) определяет планировщик (очередь потоков), на котором инициируется выполнение работы издателя (например, тяжелый фоновый поток DispatchQueue.global(qos: .userInitiated)). Оператор .receive(on: scheduler) определяет, на каком потоке подписчик будет принимать поступающие значения и события завершения (для обновления свойств UI всегда указывается DispatchQueue.main или RunLoop.main).

### 7. Как в Combine обрабатывать ошибки (например, отсутствие интернета или статус-коды 4xx/5xx от сервера)?
Ошибки обрабатываются операторами: .mapError { ... } для приведения разнородных системных ошибок к доменному enum; .catch { error in Just(fallbackValue) } для возврата резервного значения при сбое; .retry(n) для автоматического перезапуска запроса; в терминальном подписчике .sink(receiveCompletion:receiveValue:) блок receiveCompletion принимает enum Subscribers.Completion с кейсом .failure(let error).

### 8. Как с помощью Combine реализовать задержку ввода и исключение дублирующих запросов при организации поиска «на лету»?
Используется поток событий из PassthroughSubject<String, Never>(), к которому применяется оператор .debounce(for: .milliseconds(250), scheduler: RunLoop.main), ожидающий паузу в наборе текста 250 мс, и оператор .removeDuplicates(), отбрасывающий подряд идущие идентичные строки. Значение передается в поиск только после остановки ввода.

### 9. Как превратить обычное свойство класса ViewModel в источник данных Combine для автоматического обновления SwiftUI-View?
В классическом подходе Combine свойство помечается оберткой @Published var searchText: String = "". Внутренне компилятор генерирует проецируемое свойство $searchText, являющееся издателем Published.Publisher, на который можно подписаться в конвейере Combine.

### 10. В чем концептуальная разница между использованием реактивного подхода Combine и современным синтаксисом асинхронного программирования async/await (Structured Concurrency) для сетевых запросов?
async/await (структурированная асинхронность) оптимизирован для линейных дискретных операций «один запрос — один ответ», делая асинхронный код читаемым как синхронный (try await session.data(for: request)). Combine — это событийно-ориентированная реактивная парадигма для непрерывных потоков множественных событий во времени (Continuous Streams), идеально подходящая для обработки ввода в реальном времени, комбинирования нескольких источников данных (Zip, CombineLatest) и управления обратным давлением.

### DiscountCardsAPIClient.swift
```swift
import Combine
import Foundation

/// DTO карты для REST API (snake_case)
struct DiscountCardDTO: Codable, Equatable {
    let id: String
    let name: String
    let cardNumber: String
    let barcodeFormat: String
    let categoryId: String
    let colorHex: String
    let colorGradientEnd: String?
    let discountPercent: Int?
    let note: String?
    
    enum CodingKeys: String, CodingKey {
        case id, name, note
        case cardNumber = "card_number"
        case barcodeFormat = "barcode_format"
        case categoryId = "category_id"
        case colorHex = "color_hex"
        case colorGradientEnd = "color_gradient_end"
        case discountPercent = "discount_percent"
    }
}

/// Ошибки сетевого взаимодействия
enum APIError: LocalizedError, Equatable {
    case transport(String)
    case badStatus(Int)
    case decoding(String)
    
    var errorDescription: String? {
        switch self {
        case .transport(let msg): return "Сетевая ошибка: \(msg)"
        case .badStatus(let code): return "Ошибка сервера: HTTP \(code)"
        case .decoding: return "Ошибка разбора ответа сервера"
        }
    }
}

/// Клиент REST API на базе Combine
final class DiscountCardsAPIClient {
    static let defaultURL = URL(string: "https://my-json-server.typicode.com/stasevboris/RPiPiP-DiscountCards/cards")!
    private let url: URL
    private let session: URLSession
    
    init(url: URL = defaultURL, session: URLSession = .shared) {
        self.url = url
        self.session = session
    }
    
    func fetchCards() -> AnyPublisher<[DiscountCardDTO], APIError> {
        var req = URLRequest(url: url)
        req.httpMethod = "GET"
        req.setValue("application/json", forHTTPHeaderField: "Accept")
        req.timeoutInterval = 10
        
        return session.dataTaskPublisher(for: req)
            .mapError { APIError.transport($0.localizedDescription) }
            .tryMap { data, response -> Data in
                guard let http = response as? HTTPURLResponse else {
                    throw APIError.badStatus(-1)
                }
                guard (200..<300).contains(http.statusCode) else {
                    throw APIError.badStatus(http.statusCode)
                }
                return data
            }
            .decode(type: [DiscountCardDTO].self, decoder: JSONDecoder())
            .mapError { err -> APIError in
                if let apiErr = err as? APIError { return apiErr }
                return .decoding(err.localizedDescription)
            }
            .retry(1)
            .eraseToAnyPublisher()
    }
}
```

### CardExporter.swift
```swift
import Foundation

enum ExportFormat: String, CaseIterable, Identifiable {
    case json = "JSON"
    case csv = "CSV"
    var id: String { rawValue }
}

/// Экспортер данных дисконтных карт в отчуждаемый файл
struct CardExporter {
    struct ExportData: Codable {
        let format: String
        let version: Int
        let exportedAt: String
        let cardsCount: Int
        let cards: [ExportCardItem]
    }
    
    struct ExportCardItem: Codable {
        let name: String
        let cardNumber: String
        let category: String
        let discount: String
        let note: String
    }
    
    static func generateExport(cards: [DiscountCard], format: ExportFormat) -> (data: Data, filename: String) {
        let dateStr = ISO8601DateFormatter().string(from: Date())
        let cleanName = "DiscountCards_Export_\(Int(Date().timeIntervalSince1970))"
        
        switch format {
        case .json:
            let items = cards.map {
                ExportCardItem(name: $0.name, cardNumber: $0.cardNumber,
                               category: $0.categoryId, discount: "\($0.discountPercent ?? 0)%", note: $0.note)
            }
            let root = ExportData(format: "discount-cards-backup", version: 1,
                                  exportedAt: dateStr, cardsCount: items.count, cards: items)
            let encoder = JSONEncoder()
            encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
            let data = (try? encoder.encode(root)) ?? Data()
            return (data, "\(cleanName).json")
            
        case .csv:
            var lines = ["Название;Номер карты;Категория;Скидка;Заметка"]
            for c in cards {
                let row = [c.name, c.cardNumber, c.categoryId, "\(c.discountPercent ?? 0)%", c.note]
                    .map { "\"$0.replacingOccurrences(of: "\"", with: "\"\"\")\"" }
                    .joined(separator: ";")
                lines.append(row)
            }
            // Добавление UTF-8 BOM для корректного распознавания кодировки в Microsoft Excel
            let bom = Data([0xEF, 0xBB, 0xBF])
            let csvData = lines.joined(separator: "\r\n").data(using: .utf8) ?? Data()
            return (bom + csvData, "\(cleanName).csv")
        }
    }
}
```

### DebouncedSearch.swift
```swift
import Combine
import Foundation
import Observation

/// Реактивный поиск «на лету» с задержкой ввода 250 мс
@Observable
final class DebouncedSearch {
    private(set) var debouncedText: String = ""
    @ObservationIgnored private let subject = PassthroughSubject<String, Never>()
    @ObservationIgnored private var cancellable: AnyCancellable?
    
    init(delayMs: Int = 250) {
        cancellable = subject
            .map { $0.trimmingCharacters(in: .whitespacesAndNewlines) }
            .debounce(for: .milliseconds(delayMs), scheduler: RunLoop.main)
            .removeDuplicates()
            .sink { [weak self] text in
                self?.debouncedText = text
            }
    }
    
    func update(text: String) {
        subject.send(text)
    }
}
```
