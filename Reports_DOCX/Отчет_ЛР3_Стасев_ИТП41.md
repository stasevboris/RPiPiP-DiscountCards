## Контрольные вопросы
### 1. Каковы архитектурные ограничения хранилища UserDefaults? Данные каких типов и какого объема допустимо в нем хранить?
Хранилище UserDefaults загружает весь plist в память целиком при инициализации. Оно подходит исключительно для скалярных настроек приложения, флагов состояния и небольших конфигураций (до 512 КБ). Запись больших структур и частые мутации приводят к задержкам основного потока из-за постоянной дисковой синхронизации.

### 2. Что представляет собой протокол Codable/Decodable и как сопоставить ключи JSON со свойствами структуры, если их названия не совпадают?
Протокол Decodable позволяет декодировать экземпляры типов из внешних форматов (например, JSON). Несовпадающие ключи маппятся с помощью явного объявления CodingKeys: String, CodingKey, где для каждого нестандартного свойства указывается имя ключа в строковом значении.

### 3. В чем заключаются принципиальные различия между подходами к хранению данных в базах данных SQLite и Realm?
SQLite хранит данные в табличной форме с реляционными связями и требует SQL-синтаксиса и маппинга в структуры приложения. Realm хранит данные в виде нативных объектов C++ ядра с технологией Zero-Copy, где чтение свойств происходит без десериализации напрямую из отображаемой памяти.

### 4. За что отвечают компоненты ModelContainer и ModelContext в фреймворке SwiftData?
ModelContainer управляет низкоуровневым файлом базы данных, схемой моделей и миграцией. ModelContext является рабочей сессией в памяти, отслеживающей жизненный цикл объектов (вставка, мутация, удаление) и транзакционную фиксацию (метод save).

### 5. Как описываются связи между сущностями (один-к-одному, один-ко-многим) в SwiftData? Как работает каскадное удаление зависимых объектов?
Связи задаются макросом @Relationship(deleteRule:inverse:). Правило .cascade при удалении родительской записи автоматически находит и безвозвратно удаляет все ассоциированные дочерние объекты из контекста.

### 6. Что такое миграция схемы данных? В каких случаях она необходима и как реализуется при обновлении моделей?
Миграция схемы данных — это перенос пользовательских данных при изменении полей и типов моделей между релизами приложения. Реализуется через классы версий SchemaV1, SchemaV2 и явный SchemaMigrationPlan с контролем целостности.

### 7. Как извлечь отфильтрованные и отсортированные данные из локальной базы прямо в SwiftUI-интерфейс с помощью обертки свойства @Query?
Свойство @Query декларируется в структуре View с параметрами #Predicate и SortDescriptor. SwiftData связывается с механизмом Observation и автоматически обновляет интерфейс при любых изменениях соответствующих записей.

### 8. Как обеспечить потокобезопасность при работе с базой данных Realm и/или SwiftData, если запись происходит в фоновом потоке, а чтение — в главном?
В SwiftData потокобезопасность достигается использованием акторов (ModelActor), изолирующих свой ModelContext в фоновом потоке, и передачей только потокобезопасных PersistentIdentifier с последующим слиянием изменений на MainActor.

### 9. Что такое «ленивая загрузка» объектов из базы данных и как она помогает оптимизировать использование оперативной памяти устройства?
Ленивая загрузка (Faulting) удерживает в памяти легкие оболочки объектов и подгружает атрибуты и связи с диска только при непосредственном обращении к ним, экономя память при работе с большими массивами.

### 10. Какие подходы существуют для шифрования локальных баз данных на устройстве iOS/iPadOS для защиты конфиденциальной информации пользователей?
Применяется аппаратное шифрование Data Protection API на уровне файлов ОС, криптографический движок SQLCipher с 256-битным AES ключом, встроенное шифрование Realm и использование Keychain для безопасного хранения мастер-ключей.

### DiscountCardEntity.swift
```swift
import Foundation
import SwiftData

/// Модель дисконтной карты для базы данных SwiftData
@Model
final class DiscountCardEntity {
    @Attribute(.unique) var id: UUID
    var name: String
    @Attribute(.unique) var cardNumber: String
    var barcodeFormatRaw: String
    var categoryId: String
    var colorHex: String
    var colorGradientEnd: String?
    var discountPercent: Int?
    var note: String
    var remoteId: String?
    var locallyModified: Bool
    var createdAt: Date
    
    init(id: UUID = UUID(), name: String, cardNumber: String,
         barcodeFormat: BarcodeFormat = .ean13, categoryId: String,
         colorHex: String = "#e11d48", colorGradientEnd: String? = nil,
         discountPercent: Int? = 5, note: String = "",
         remoteId: String? = nil, locallyModified: Bool = false,
         createdAt: Date = .now) {
        self.id = id
        self.name = name
        self.cardNumber = cardNumber
        self.barcodeFormatRaw = barcodeFormat.rawValue
        self.categoryId = categoryId
        self.colorHex = colorHex
        self.colorGradientEnd = colorGradientEnd
        self.discountPercent = discountPercent
        self.note = note
        self.remoteId = remoteId
        self.locallyModified = locallyModified
        self.createdAt = createdAt
    }
    
    var barcodeFormat: BarcodeFormat {
        get { BarcodeFormat(rawValue: barcodeFormatRaw) ?? .ean13 }
        set { barcodeFormatRaw = newValue.rawValue }
    }
}
```

### CategoryCatalog.swift
```swift
import Foundation

/// Каталог категорий, загружаемый из неизменяемого JSON-файла
final class CategoryCatalog {
    static let shared = CategoryCatalog()
    
    struct CategoryItem: Decodable, Identifiable {
        let id: String
        let name: String
        let icon: String
        let color: String
    }
    
    private struct RootFile: Decodable {
        let version: Int
        let categories: [CategoryItem]
    }
    
    let categories: [CategoryItem]
    private let map: [String: CategoryItem]
    
    init(data: Data) throws {
        let root = try JSONDecoder().decode(RootFile.self, from: data)
        self.categories = root.categories
        self.map = Dictionary(uniqueKeysWithValues: root.categories.map { ($0.id, $0) })
    }
    
    convenience init() {
        guard let url = Bundle.main.url(forResource: "categories", withExtension: "json"),
              let data = try? Data(contentsOf: url) else {
            fatalError("Не найден обязательный файл categories.json")
        }
        try! self.init(data: data)
    }
    
    func category(for id: String) -> CategoryItem {
        map[id] ?? CategoryItem(id: "other", name: "Другое", icon: "creditcard", color: "#64748b")
    }
}
```

### CardFormView.swift
```swift
import SwiftUI

/// Форма добавления и редактирования дисконтной карты
struct CardFormView: View {
    @Environment(\.dismiss) private var dismiss
    @State private var viewModel: CardFormViewModel
    
    init(viewModel: CardFormViewModel) {
        _viewModel = State(initialValue: viewModel)
    }
    
    var body: some View {
        @Bindable var viewModel = viewModel
        NavigationStack {
            Form {
                Section("Данные карты") {
                    TextField("Название (напр., Евроопт)", text: $viewModel.name)
                    TextField("Номер карты / штрихкода", text: $viewModel.cardNumber)
                        .keyboardType(.numberPad)
                }
                
                Section("Категория") {
                    Picker("Категория", selection: $viewModel.categoryId) {
                        ForEach(CategoryCatalog.shared.categories) { cat in
                            Label(cat.name, systemImage: cat.icon).tag(cat.id)
                        }
                    }
                }
                
                Section("Цветовое оформление") {
                    ColorPickerPresets(selectedColor: $viewModel.colorHex)
                }
                
                Section("Заметка") {
                    TextField("Необязательно", text: $viewModel.note, axis: .vertical)
                }
                
                if let err = viewModel.errorMessage {
                    Section {
                        Text(err).foregroundStyle(.red)
                    }
                }
            }
            .navigationTitle(viewModel.title)
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Отмена") { dismiss() }
                }
                ToolbarItem(placement: .confirmationAction) {
                    Button("Сохранить") {
                        if viewModel.save() { dismiss() }
                    }
                    .disabled(!viewModel.canSave)
                }
            }
        }
    }
}
```
