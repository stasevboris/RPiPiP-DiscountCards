1. ОТЧЁТЫ В ФОРМАТЕ DOCX:
   В папке Reports_DOCX/ находятся 4 готовых отчёта в формате Microsoft Word (.docx),
   оформленные строго по ГОСТ и стандарту ГГТУ им. П. О. Сухого:
   - Отчет_ЛР1_Стасев_ИТП41.docx (SwiftUI, интерфейс, поиск, категории)
   - Отчет_ЛР2_Стасев_ИТП41.docx (MVVM, штрихкоды, сканер Vision)
   - Отчет_ЛР3_Стасев_ИТП41.docx (SwiftData, CRUD, categories.json)
   - Отчет_ЛР4_Стасев_ИТП41.docx (REST API, Combine, синхронизация, экспорт)

2. ПУБЛИКАЦИЯ В GITHUB:
   Создайте открытый репозиторий RPiPiP-DiscountCards и выполните в терминале:
     git init
     git add .
     git commit -m "feat: complete discount cards iOS application"
     git tag lab1
     git tag lab2
     git tag lab3
     git tag lab4
     git remote add origin https://github.com/ВАШ_АККАУНТ/RPiPiP-DiscountCards.git
     git push -u origin main --tags

3. ЗАПУСК В БРАУЗЕРЕ (БЕЗ MAC) ЧЕРЕЗ APPETIZE.IO:
   Перейдите в репозитории на GitHub во вкладку "Actions".
   Слева выберите "Run App in Browser (Запустить симулятор)" (.github/workflows/remote.yml).
   Нажмите "Run workflow".
   Через 1 минуту откройте выполненный запуск, скачайте архив "DiscountCards-Simulator-App.zip" из вкладки Summary (Сводка).
   Зайдите на сайт https://appetize.io/upload и загрузите туда этот архив.
   Нажмите "View App" и в боковом меню выберите устройство с iOS 17 (например, iPhone 15 Pro).
