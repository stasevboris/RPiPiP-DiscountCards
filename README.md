## Назначение
Мобильное приложение для каталогизации дисконтных карт со встроенным модулем сканирования штрихкодов под iOS 17+.

## Структура лабораторных работ и Git-тегов:
- `lab1` — Проектирование UI на SwiftUI (каталог карт, быстрый поиск, фильтрация по категориям).
- `lab2` — Архитектура MVVM, генерация штрихкодов CoreImage, сканирование AVFoundation + программный mock.
- `lab3` — Хранилище SwiftData, CRUD-операции, статический классификатор `categories.json` (Decodable).
- `lab4` — REST API клиент на Combine, синхронизация слиянием при старте, экспорт JSON/CSV через ShareLink.

## Сборка локально через XcodeGen:
```bash
brew install xcodegen
xcodegen generate
open DiscountCards.xcodeproj
```
